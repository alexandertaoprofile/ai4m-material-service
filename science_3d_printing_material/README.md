# science_3d_printing_material

3D 打印耗材与复合材料工程筛选服务（建设中）。当前从 `inorganic_new_material` 轻量服务骨架复制而来，用于承接“3D 打印耗材/纤维增强复合材料/增材制造结构件”这类不适合直接走 MP/ALIGNN 无机晶体化学式检索的问题。

## 当前定位

该服务未来面向需求驱动的耗材选型，而不是化学式驱动的晶体数据库检索。

典型输入包括：

- 机器人关节 3D 打印结构件
- PA12-CF / PA6-CF / PLA-CF / PEEK-CF 等耗材体系
- 高强度、高刚度、抗疲劳、层间结合力、尺寸稳定性、打印窗口、成本等需求

## 计划链路

1. 需求解析：从用户问题和 LS 文献筛选结果中提取应用场景、性能约束和工艺约束。
2. 候选耗材抽取：识别 PA12/C、SCF-PA12、CF-PA6、PLA-CF、PEEK-CF 等聚合物/纤维增强体系。
3. 已有耗材筛选：基于 datasheet、文献和材料说明书指标，对候选耗材做满足度排序。
4. 缺口分析：说明强度、刚度、疲劳、层间结合、尺寸稳定性、热变形温度、打印难度和成本中哪些不足。
5. 方案建议：若已有耗材不能完全满足，给出基体、增强相、纤维长度/取向、体积分数、打印路径和后处理方向。
6. 验证建议：输出需要补充的拉伸、弯曲、冲击、疲劳、层间剪切、热变形、吸水率和尺寸稳定性测试。

## 与无机已有材料服务的区别

- 不以 Materials Project 命中为前提。
- 不把 PA12/C 这类耗材表达拆成单个元素去跑 MP。
- 不用 E_above_hull、band_gap、bulk_modulus 等晶体性质作为主结论。
- 更关注 datasheet 指标、工艺窗口、复合材料结构和实际打印性能。
