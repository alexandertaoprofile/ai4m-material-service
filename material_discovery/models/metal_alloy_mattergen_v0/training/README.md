# 历史金属晶体模型训练与验收流程

本页描述 `metal_alloy_mattergen_v0` 的离线训练准备，属于历史模型包。当前模型清单仍为 `scaffolded`，没有登记已验收权重；本流程不属于 OMatG 线上推理步骤。状态和文件结构见[上级说明](../README.md)。

## 1. 开始训练前需要什么

- 已审核的完整 JARVIS 结构数据及[数据清单](../data/README.md)。
- 本地 MatterGen 基座、独立计算环境和可用 GPU。
- 已确定的训练/验证/测试划分、缓存转换配置及输出目录。
- 足够的 `/data` 空间，用于数据缓存、权重和运行日志。

训练是用数据调整模型参数；微调是从已有基座继续训练；推理是用完成训练的参数生成结构。正常用户请求只需要推理。

## 2. 执行顺序和产物

| 阶段 | 操作 | 应保存的产物 |
| --- | --- | --- |
| 数据审核 | 核对源结构、过滤规则及独立划分。 | `data/dataset_manifest.json` 和可取得的实际数据。 |
| 缓存转换 | 将最终 CSV 转为 MatterGen 数据缓存，训练与验证采用同一标准化规则。 | 缓存目录、转换配置及版本。 |
| 基座微调 | 从 `mattergen_base` 开始，按确定的配置训练。 | `outputs/` 中的配置、软件版本、随机种子、数据校验和及训练日志。 |
| 权重登记 | 保存最佳 checkpoint 并计算 SHA-256。 | `checkpoints/` 的权重及更新的模型清单，原通用权重保持独立。 |
| 独立验收 | 使用独立化学体系，核验结构有效性、组成覆盖、重复率及稳定性。 | 独立评价记录、MatterSim/参考相评价设置和验收结论。 |

只有独立验收通过，才把 [model_manifest.json](../model_manifest.json) 状态更新为 `accepted`。训练完成、指标较好或权重文件存在，都不能代替服务接入验收。

## 3. 命令与后续接入

本包没有提供已经锁定并验证的完整微调命令。数据、GPU、MatterGen 数据模块配置及输出位置确认后，再形成对应版本的命令和日志，避免使用未经审核的数据启动训练。

即使完成训练，也需单独配置旧后端适配、记录模型版本并运行接口与真实任务验收。当前 1115 的 OMatG 部署入口见[服务 README](../../../README.md)，不因本训练包状态变更而自动切换。
