# 1115 OMatG：多元素组成探索

当前是独立影子测试版本。线上1115及弹窗未修改或重启；模型权重未改变。

## 修正的对象

先前Fe-Cr-Ni白名单、仅Fe必含的8原子测试生成10个纯Fe/Cr/Ni晶胞。白名单保证元素不越界，但未引导混合组成；纯Fe也能通过必含Fe的条件。这批记录保留，不将旧结果追溯改成新约束下的成功结果。

新版本对多元素DNG默认至少两种元素；单元素DNG及固定化学式CSP保留原组成。允许元素与必含元素继续分开确认，不自动要求整个白名单全出现，也不从上文助手文本推断组成。

## 采样约束而非修改输出结构

对于白名单多元素探索，服务在OMatG联合积分开始前，设置少量必含元素位点。可选元素在候选之间轮换；至少覆盖最少元素种数。通常最多锚定一半位点，必含种数超过一半时只使用满足该条件的最少位点，其余物种仍由原DNG离散流选择。锚定元素在积分中保持，晶格和坐标在含有这些元素的上下文中同时生成。

这是服务侧的部分位点条件采样启发式，不是官方条件DNG检查点、不做重训练/IRL、也不在采样结束后给纯Fe结构换元素。锚定模板、策略、原子计数及模型权重哈希写入生成记录。IndependentSampler先在CPU创建状态，再交给CUDA积分；专项回归覆盖该设备迁移。

默认开放空间DNG保留原生元素选择，只增加至少两种元素的后筛条件；不为它随机强加稀有元素锚点。明确的开放空间必含元素可单独锚定，剩余多元素条件仍复核。

这些约束改善组成覆盖，不保证几何、收敛、稳定性、新颖性或实际工程性能。几何不合格仍记录失败，松弛和性质链路仍由既有MatterSim/ALIGNN处理。DNG默认直接评估，没有强制追加CSP。

## 与同事的弹窗字段衔接

沿用现有`new_material`请求对象和原接口/event/step ID。以下是可选的生成条件，不引入新的前端等待状态：

| 字段 | 含义与默认 |
| --- | --- |
| `allowed_elements` | 可以出现的元素；不等同全部必含 |
| `required_elements` | 必须出现的元素，允许集合的子集 |
| `min_distinct_elements` | 最少元素种数；多元素/开放DNG默认至少2，多个必含元素时默认至少覆盖必含种数；单元素与CSP默认1 |
| `dng_species_strategy` | `auto`按任务选择部分位点锚定或白名单掩码；`presence_anchors`显式锚定；`masked`仅白名单掩码，可用于原采样对照 |

`min_distinct_elements=1`明确允许单质，但不撤销必含元素条件。只给Fe的任务自动保留单质，不强行增加未知元素。要探索Fe-Cr-Ni三元组成，应明确将三者写入`required_elements`；只写白名单及`min_distinct_elements=2`仍允许二元组成。

示例：

```json
{
  "new_material": {
    "generation_mode": "dng",
    "allowed_elements": ["Fe", "Cr", "Ni"],
    "required_elements": ["Fe", "Cr", "Ni"],
    "min_distinct_elements": 3,
    "num_atoms": 8,
    "max_candidates": 10,
    "refine_with_csp": false,
    "seed": 51
  }
}
```

## 展示与结果核验

保留Welcome风格的五段标题与上文场景承接。生成多样性单独统计单质数、多元素数、约分后的不同组成数；与收敛结构族数及新颖性区分。候选比较增加完整晶胞原子计数和元素种数。近似重复候选仍展示自己的失败/缺证状态，不用去重标记掩盖未收敛。

8原子晶胞的原子计数对应12.5 at.%的离散步长，仅为小晶胞组成/构型探索。这里不将上文真实RSS-021质量配方换算为这些有序晶体，也不称为火箭外壳材料已经验证。

完整验证命令入口是`tools/verify_omatg_diversity.py`；每例10个候选，可选择原白名单对照、Fe必含二元/多元探索、Fe-Cr-Ni三者必含、Li-Al-O、单质及开放空间。`--generation-only`只验证实际采样和几何，不声称完成稳定性或性质计算。
