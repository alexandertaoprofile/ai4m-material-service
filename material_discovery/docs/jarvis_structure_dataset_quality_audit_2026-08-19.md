# JARVIS 晶体结构集质量审计（用于金属合金 MatterGen 微调）

## 可用结论

针对金属间化合物/有序合金结构发现，平台的 `material.jarvis_structure`
可以作为 MatterGen 微调的**结构主数据源**：它同时给出晶格、坐标、元素、
化学式、形成能、带隙、`E_hull` 与空间群。高温合金性能表则只作为后续
性能标签或排序证据，不能替代该结构集。

在数据适配时，必须以 `structure.elements` 的实际位点数为准，不能直接以
顶层 `atom_count` 过滤。还必须将有限温度无序合金、成分配比和工程性能
目标留在合金配比/性能服务中；本数据集描述的是有序晶体结构及其 DFT 标签。

## 金属合金候选覆盖（深度快照）

金属候选的保守定义为：结构中全部元素为金属元素，且含至少两种元素；
`Tc`、`Pm` 和原子序数不低于 84 的元素另列为不进入首版模型的元素，保持
与 MatterGen 官方 Alex-MP-20 训练范围一致。

| 过滤层 | 快照记录数 |
|---|---:|
| 多元素全金属结构 | 3,300 |
| 排除首版不支持元素后 | 3,085 |
| 实际位点≤20 且 `E_hull≤0.05` | 720 |
| 实际位点≤20 且 `E_hull≤0.10` | 905 |
| 实际位点≤20 且 `E_hull≤0.20` | 1,382 |

样本中 Fe、Co、Ni、Cr、Mo、W、Ta、Nb、Ti、V、Al 均已出现，说明该源能覆盖
常见高温/难熔合金的元素空间；但最终训练集必须按目标体系重新统计覆盖与类别
均衡，避免 Be 富集或少数原型主导扩散模型。

## 首版训练数据准入规则

1. 以 `structure` JSON 重建 `pymatgen.Structure`，再标准化为原胞或 Niggli
   约化胞；使用重建后的实际位点数。
2. 要求元素、坐标、晶格均完整，晶胞体积为正，且无部分占位；记录排除原因。
3. 首版只保留目标金属元素集合中的二元及以上有序结构，实际位点≤20，
   `E_hull≤0.10 eV/atom`。`≤0.05` 用于稳定优先子集；`0.10–0.20` 只作为
   独立的亚稳态探索/评测池，不作为既有条件模型的输入外推。
4. 对相同化学体系按结构匹配去重，并按化学体系而非随机记录切分
   train/validation/test，避免原型泄漏。
5. 将形成能、`E_hull`、带隙和密度统一为训练标签；工程强度、蠕变与热处理
   数据通过材料牌号/成分的可追溯映射另行加入，不能伪造为结构级 DFT 标签。
