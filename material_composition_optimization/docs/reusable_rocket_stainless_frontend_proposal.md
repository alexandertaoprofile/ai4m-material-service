# 可回收火箭不锈钢配方设计：用户页面草案

## 用户打开后看到什么

在“合金成分设计与服役性能筛选”中增加第三张服务卡：

> **可回收火箭不锈钢配方设计**
> 面向贮箱、箭体承压壳体等薄壁结构，比较奥氏体不锈钢的成分、制造状态与目标温度下的强度—延性取舍，并给出进入低温、焊接和疲劳验证的优先级。

卡片不出现“30X 预测”字样。说明文字可写为：

> 以 301、304L 等公开低温奥氏体不锈钢为基准，帮助设计下一轮可验证的候选配方；专有牌号只作为应用背景，不作为已知训练标签。

页面默认呈现“适合先做什么”，而不是要求用户理解合金模型。提供两个入口：

| 入口 | 适合的提问 | 页面结果 |
|---|---|---|
| **设计新候选** | “希望比 304L 更高强、仍保留低温延性” | 给出受边界约束的候选成分、工艺建议和验证优先级。 |
| **比较已有路线** | “301 冷作、304L 和某一现有配方怎样取舍？” | 按相同温度和状态并列比较，并提示需要补齐的状态信息。 |

## 输入页

### 1. 先说明部件与环境

| 字段 | 用户看到的说明 | 示例 / 规则 |
|---|---|---|
| 部件 | 材料将用在哪里？ | LOX/LCH4 贮箱筒段、箭体外壳、穹顶、加强件、地面贮箱。 |
| 主要任务 | 此次优先解决什么？ | 减重、提高承压强度、低温延性、可制造性、焊接后的性能保持。可多选并排序。 |
| 目标温度 | 选择材料真正需要比较的温度。 | 20 °C、−196 °C、−183 °C（LOX）、−162 °C（LCH4）或自定义。 |
| 结构状态 | 输入会影响结果解释。 | 板厚；母材 / 焊缝 / 热影响区；无焊接时可选“母材”。 |
| 预期制造路线 | 不确定时可选择“待比较”。 | 退火板、冷作板、cryoforming、焊后处理。 |

温度旁不直接显示“低温模型不可用”，而使用状态提示：

| 用户选择的温区 | 页面提示 | 输出方式 |
|---|---|---|
| 20–111 K | **低温验证优先模式**：已切换为 301/304L 可追溯参考与试验排序。 | 给出基准对比、候选验证优先级和所需试验；不显示自由配方的数值强度预测。 |
| 293–1273 K | **配方筛选模式**：可在已有公开数据邻域内比较候选。 | 显示屈服强度、抗拉强度、延伸率预测及适用域。 |
| 高于 1273 K | **需扩展数据模式**：当前短时拉伸训练数据未覆盖该温区。 | 保留用户条件，展示可补数据项并建议转入高温镍基或耐热钢路线核对。 |

### 2. 设置配方边界

默认显示简洁的“核心元素”面板；用户点击“更多元素”后才看到扩展项。

| 分组 | 元素 | 输入形式 | 页面规则 |
|---|---|---|---|
| 基体 | Fe | 自动平衡 | Fe = 100 − 其他元素之和；不要求用户手算。 |
| 奥氏体与耐蚀基础 | Cr、Ni、Mn | 最小值—最大值（wt.%） | 必填。初始范围来自训练适用域，用户可收窄。 |
| 强化与稳定化 | C、N、Si、Mo、Nb、Ti、Cu | 可选范围（wt.%） | 仅展示已覆盖元素；超出邻域时即时标识“需要人工复核”。 |
| 约束 | 总和、禁用元素、成本偏好 | 自动检查 / 可选 | 页面显示剩余 Fe 与配方是否可行。 |

页面在输入区右侧固定显示：

```text
当前配方空间：Fe–Cr–Ni–Mn 奥氏体不锈钢
单位：wt.%（质量百分比）
已知范围内：Cr 15.9–21.1；Ni 8.4–34.5（仅作模型适用域提示，不是材料规范）
```

### 3. 选择比较目标

用户用“优先级”替代复杂权重；高级设置才显示权重滑杆。

| 目标 | 用户理解 | 可选优先级 |
|---|---|---|
| 抗永久变形 | 0.2% 屈服强度 | 高 / 中 / 低 |
| 最大承载 | 抗拉强度 UTS | 高 / 中 / 低 |
| 成形余量 | 延伸率 | 高 / 中 / 低 |
| 制造可行性 | 冷作、焊接与板厚约束 | 必填说明，当前不纳入单一数值评分。 |
| 低温、焊接、疲劳、LOX 相容性 | 后续验证项目 | 勾选后进入“验证重点”，不从拉伸模型外推数值。 |

提交按钮：**生成候选与验证优先级**。

## 结果页

结果页以“先回答、再展开证据”的顺序呈现；每次结果均固定带出用户输入的部件、温度、板厚和材料状态，避免脱离工况阅读数值。

### 顶部结论卡

示例文案：

> 针对 **LOX/LCH4 贮箱筒段**，在 **−183 °C、母材、冷作板状态** 下，当前证据支持先以 **301/304L 低温参考路线** 规划试验；本次候选配方用于缩小下一轮 Cr–Ni–Mn 成分窗口，优先验证冷作后屈服强度、延伸率和焊后低温韧性。

右侧显示三枚清晰状态标签：

| 标签 | 含义 |
|---|---|
| **可比较** | 成分、温度和已知工艺均在训练邻域内。 |
| **需要复核** | 靠近成分边界，或关键工艺信息不完整。 |
| **先做试验** | 低温、焊接、疲劳、断裂或 LOX 相容性等当前没有自由配方预测。 |

不得将“可比较”显示为“通过认证”或“工程可用”。

### 候选卡（最多 3 个）

每张卡只给出足以决策的内容，并允许展开查看完整证据。

| 区块 | 显示内容 |
|---|---|
| 候选身份 | “火箭壳体不锈钢候选 01”，而非虚构牌号或 30X。 |
| 配方 | Fe 平衡；Cr、Ni、Mn、C、N、Si 等 wt.%；同时显示总和 100%。 |
| 预期制造状态 | 本轮假设或用户给出的退火 / 冷作 / cryoforming 状态；未给出时明确显示“需确认”。 |
| 目标温度下的比较 | 仅在 293–1273 K 时显示：0.2% 屈服、UTS、延伸率预测值及模型误差带。 |
| 相对基准 | 与用户选定的 301 或 304L 参考路线相比的“强度 / 延性取舍”，而非将基准性能改称候选实测值。 |
| 适用域 | 成分邻域状态、最近邻距离、温度范围与“可比较 / 需要复核”。 |
| 下一步 | 例如“77 K 母材拉伸 → 焊缝/HAZ 拉伸 → Charpy 或断裂韧性 → 低周疲劳 → LOX 相容性”。 |

模型误差必须和数值放在同一行，例如：

| 性能 | 本轮筛选结果 | 适用条件 |
|---|---|---|
| 0.2% 屈服强度 | 680 MPa（模型筛选值；典型验证 MAE 16 MPa） | 293 K；候选成分与指定处理状态；仅用于候选排序。 |

上表数字仅为版式示例，页面实际只渲染本次模型计算返回的数值。

### 三张图，避免“炫技仪表盘”

| 图 | 用途 | 显示规则 |
|---|---|---|
| **强度—延性取舍图** | 看候选相对 301/304L 的取舍。 | 横轴延伸率，纵轴屈服强度；不同温度或不同材料状态不得混在同一比较组。 |
| **候选成分条形图** | 看三张候选卡究竟差在哪里。 | 堆叠 wt.%；Fe 为平衡部分；标出用户设置的元素边界。 |
| **适用域与验证路径图** | 把“模型结果”和“还需要做的试验”说清楚。 | 左侧为温度/成分邻域状态，右侧为低温、焊接、疲劳、LOX 的验证步骤；不将缺失项绘制为失败。 |

现有 1111 前端保持既有 WebSocket 文本流与 `MaterialsPNG` 资产协议。首版只需将上述内容组织为两段 Markdown，并按已有资产机制发布这三类 PNG；不新增事件类型或前端传输协议。

### 证据与边界（可展开）

展开区避免大段模型术语，只展示对用户决策有用的四项：

| 项目 | 当前覆盖 | 用户如何使用 |
|---|---|---|
| 配方筛选模型 | 2,180 条屈服/UTS、2,083 条延伸率观测；293–1273 K。 | 用于此温区内的候选排序。 |
| 低温参考 | 301/304L 的可追溯低温拉伸参考。 | 用于选定低温试验优先级和对比基准。 |
| 当前未形成自由配方预测的项目 | 焊接、疲劳、断裂韧性、LOX 相容性。 | 随候选卡生成验证计划，不用强度结果替代。 |
| 专有 30X | 没有公开、可训练的完整成分—工艺—性能标签。 | 只作为火箭应用背景；不命名为 30X 性能预测。 |

## 与另外两个模块的成熟度表达

页面无需让用户看到模型内部版本，但产品侧应使用不同的展示强度：

| 模块 | 当前可交付能力 | 建议对外状态 |
|---|---|---|
| 高熵/多主元合金 | 受约束配方生成、强度/硬度/相风险比较。 | 配方探索。 |
| 高温镍基合金 | 围绕已知牌号邻域比较短时强度与蠕变寿命。 | 条件性能筛选。 |
| 可回收火箭不锈钢 | 293–1273 K 拉伸候选排序，外加低温参考与验证路径。 | **条件配方筛选 + 低温验证规划**。 |

因此三者可以进入同一个 1111 服务入口，但火箭不锈钢首版不应使用“全性能预测”“自动最优配方”或“已达到 30X”类文案。

## 首版需要落地的字段映射

```text
model_domain: reusable_rocket_stainless
composition_unit: wt.%
composition: Fe（自动平衡）+ Cr/Ni/Mn/C/N/Si/... 边界或候选值
component: 贮箱/壳体/穹顶/加强件
temperature_K: 目标温度
material_state: annealed / cold_worked / cryoformed
thickness_mm: 可选
weld_state: base_metal / weld / HAZ
objectives: yield_strength / UTS / elongation 的优先级
verification_focus: cryogenic_toughness / fatigue / weld / LOX_compatibility
```

结果 manifest 最少包含：候选 wt.%、用户工况、预测值和验证误差、适用域状态、参考牌号、未覆盖验证项、图表资产地址。任何低温参考数据都要以 `reference_only` 标记与自由配方模型输出分开保存。

## 上线前的界面验收

1. 用户选择 −183 °C 时，不出现自由配方强度数值，改为低温参考与验证路径。
2. 用户选择 293 K 且配方在适用域内时，候选卡必须同时显示成分、工艺状态、预测误差和适用域。
3. 用户输入超出 Cr/Ni 等训练邻域的范围时，页面保留输入但显示“需要复核”，并禁止其获得“最优”标签。
4. 301/304L 只能标为参考牌号，不能在结果中被重命名为 30X。
5. 焊接、疲劳、断裂韧性和 LOX 相容性必须以验证事项呈现，不能从拉伸预测表自动填入数值。
6. 保持当前 1111 的 `/start`、`/alloy/start`、固定步骤 ID、事件顺序和 `MaterialsPNG` 资产类型不变。
