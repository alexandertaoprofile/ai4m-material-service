## 结果：先看应该优先做什么

> 针对 **可回收火箭贮箱或承压壳体（母材）**，在 **293 K、固溶退火基线状态** 下，服务会从当前成分邻域中保留可比较候选。优先候选用于安排下一轮拉伸、低温、焊接和疲劳试验；不是商品牌号，也不代表 30X 性能。

| 当前状态 | 这对本次结果的含义 |
|---|---|
| 🟦 **可比较** | 成分、温度在训练邻域内；可用于当前候选之间的排序。 |
| 🟧 **需要复核** | 成分接近数据边界，或工艺信息仍不完整；可保留为探索候选。 |
| 🧪 **先做试验** | 90/111 K、焊缝、疲劳、断裂韧性和 LOX 相容性由试验验证。 |

## 低温、焊接与可回收性：下一步怎样验证

| 验证关卡 | 建议动作 | 服务当前提供的帮助 |
|---|---|---|
| 90 K（液氧） | 母材拉伸；按需要补 Charpy 或断裂韧性。 | 301/304L 可追溯低温参考和候选优先级。 |
| 111 K（液甲烷） | 与 90 K 相同状态下复测。 | 避免将常温强度直接当成低温性能。 |
| 焊缝与 HAZ | 与母材分开做拉伸和低温韧性。 | 将焊接状态写入任务并列为独立验证项。 |

| LOX 环境 | 材料、表面状态和污染控制下的相容性验证。 | 不用拉伸强度替代相容性判断。 |
