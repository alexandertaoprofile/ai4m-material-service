# HEA 热力学数据与服务架构审计（2026-07-15）

## 结论摘要

当前 HEA/MPEA 服务是**实验数据驱动的代理评价器**，含少量成分物理描述符和统计约束；不是 CALPHAD 耦合模型，也不是 PINN。可在不增加外部软件依赖的前提下继续使用；但不能将它表述为已具备热力学相平衡约束。

## 数据审计

### 实验 HEA/MPEA 统一表

`hea_surrogate/data/processed/experimental_canonical.csv`：2018 条、70 列。

| 字段组 | 覆盖 | 审计结论 |
|---|---:|---|
| `phase_standardized` | 1335 | 可训练实验相分类；不是平衡相分数。 |
| 测试温度 | 1347 | 可作为强度模型输入。 |
| 工艺 | 1386 | 可作为类别输入，但粒度有限。 |
| 实验密度 | 107 | 不足以训练通用实验密度模型。 |
| 计算密度 | 1503 | 原始计算字段，应标记来源和定义后才能单独建模。 |
| 计算 Young 模量 | 714 | 可用于独立、带来源标签的辅助模型；不应直接当实验标签。 |
| 混合焓、Omega、熔点/电负性/剪切模量差、混合熵、VEC | 401 | 仅子集覆盖；不能作为所有 HEA 强度样本的原始输入。 |

任务子集覆盖：屈服强度 1255 条（上述热力学描述符 160 条），硬度 852 条（241 条），相分类 1335 条（这些描述符字段为 0）。

因此：目前可从成分可靠重算的混合熵、VEC可作为统一特征；原始字段只能保留为可追溯证据。混合焓、Omega 等需要统一元素属性/二元交互参数表重新计算，或由 CALPHAD/独立代理提供，才可进入全量模型。

### Nb-Cr-V-W-Zr 计算表

`nbcrvwzr_calculated.csv`：10626 条。下列字段覆盖约 10513–10626 条：液相线/固相线、500/1000/1500°C CTE、多温度热导率和密度、多温度 BCC 相分数、1000/1500°C 屈服强度 prior、Single BCC、Scheil 相信息、Creep Merit。

结论：该表适合独立 Nb-Cr-V-W-Zr 计算代理模型；不得与实验 HEA/MPEA 强度或相标签纵向混合。

## 当前模型实际使用的物理信息

输入为元素原子分数、元素数、由成分计算的混合熵、平均原子序数、平均 VEC、工艺类别、温度。模型比较 Ridge、ExtraTrees、MLP 后，为每个任务选择模型并以 5 个随机种子集成。相风险规则为 `P(IM) + P(SS+IM) < 0.5`；适用域由未见元素、元素范围和最近训练成分距离判定。

未接入：CALPHAD 相平衡、相分数、混合焓统一重算、析出/晶界/固溶强化机制、显式氧化/蠕变机制。

## 优化函数：当前与未来

当前可合法使用的非线性多目标评分为：

`J(x) = w_y*z(YS_hat(x)-sigma_YS(x)) + w_h*z(HV_hat(x)) + w_p*z(P_SS(x)) + w_r*[0.5*(1-z(sigma_YS(x))) + 0.5*(1-z(d_AD(x)))]`

约束：`sum_i x_i = 1`，元素上下界，`P_IM+P_SS+IM < p_max`，不确定性上限，适用域规则。

其中 `YS_hat/HV_hat` 为现有集成代理预测，`sigma` 是 5 模型离散度，`P_SS` 是固溶体相类别概率，`d_AD` 是距训练成分的距离。`z` 表示在当前可行候选空间内归一化；默认权重为强度 0.55、硬度 0.25、相稳定倾向 0.10、可靠性 0.10，且可由调用方配置。元素范围、相风险、不确定性和适用域规则是排序前先执行的硬约束。

截图中含 `Omega_ij`、混合熵和 GP 不确定性的公式是一种**物理引导的采集函数范式**，不是当前服务已部署的公式。要合法使用其中的混合焓项，需要经过核验的二元交互参数表；要使用 GP 标准差，需要用 GP 替换/并行训练当前代理。
