# 高温镍基合金配比筛选结果

针对**单晶热端叶片**场景，在 **950 °C、250 MPa** 以及当前设定热处理条件下，优先评估候选 **NIH-002**。它位于当前训练成分覆盖范围内，在本轮候选中呈现出较好的短时承载与蠕变寿命平衡，建议进入下一步相稳定性、抗氧化和定向力学验证。

## 这些数值对研发意味着什么

| 指标 | 当前作用 |
|---|---|
| 短时 UTS | 比较指定温度下的短时抗拉承载能力。该模型独立 Tag 测试 MAE 约为 111 MPa。 |
| 0.2% proof strength | 辅助比较指定温度下抵抗塑性变形的能力。独立 Tag 测试 MAE 约为 86 MPa。 |
| 蠕变断裂寿命 | 比较指定温度、载荷、路线和热处理下的耐久优先级。独立 Tag 测试 MAE 为 0.259 log10(h)，约对应 1.81 倍寿命筛选因子。 |
| 延伸率 | 作为拉伸延性辅助信息展示，不作为单独放行门槛。 |
| 硬度 | 当前数据目录未收录可训练标签，因此本服务不输出硬度预测。 |

## 建议的下一步

1. 对 NIH-002 及来源锚点合金同步做 CALPHAD 相稳定性筛查，重点确认不利相风险。
2. 根据实际服役环境补充氧化/腐蚀筛查。
3. 选择前 2–3 个候选，在相同热处理条件下安排高温拉伸与蠕变验证。

当前结果用于缩小验证范围和安排研发优先级，不替代材料工程放行或制备结论。
