# 热端镍基合金配比筛选（用户可见版）

## 适用场景

面向燃气涡轮、航空发动机热端等需要同时关注短时承载与高温耐久的镍基合金配比探索。用户输入元素质量百分比范围、制造路线、热处理、目标温度和蠕变载荷；服务返回可继续验证的候选优先级，而不是材料数据库的简单检索结果。

## 用户会看到的流程

```text
成分边界 + 路线 + 热处理 + 温度/载荷
                │
                ▼
来源合金锚点筛选
（同路线、同元素体系的剑桥高温合金记录）
                │
                ▼
局部成分探索
（只扰动来源合金中已存在的溶质，Ni 自动平衡；不引入新元素）
                │
                ▼
条件性能预测
短时 UTS · 0.2% proof strength · 蠕变断裂寿命
                │
                ▼
保守排序与研发短名单
                │
                ▼
CALPHAD / 氧化评估 / 定向力学试验
```

## 结果卡片如何阅读

| 信息 | 对研发决策的意义 |
|---|---|
| 成分（wt.%） | 可直接进入配料与 CALPHAD 输入的候选组成；总和为 100 wt.% 。 |
| 短时 UTS | 指定温度下的短时抗拉承载能力，用于初步比较强度。 |
| 0.2% proof strength | 指定温度下的屈服相关指标，用于辅助评估抗塑性变形能力。 |
| 蠕变断裂寿命 | 指定温度、载荷、路线和热处理下的耐久优先级，不脱离工况比较。 |
| 延伸率 | 拉伸延性辅助信息；当前不作为单独放行门槛。 |
| 来源锚点 / 数据适用域 | 说明候选从哪个已记录合金附近探索，以及它是否位于训练成分范围内。 |

## 当前模型边界

- 数据来自剑桥高温合金数据库的可追溯文献与行业数据汇编；模型按合金 Tag 分组保留独立测试。
- 当前可用于保守提议的范围为：700–1093 °C、80–740 MPa；制造路线以铸造和单晶为主。DS 蠕变记录较少，只适合审慎比较。
- 独立 Tag 测试的误差量级：UTS 111 MPa，0.2% proof strength 86 MPa，蠕变寿命 0.259 log10(h)，约对应 1.81 倍寿命因子。
- 当前数据目录没有可训练的硬度标签，因此服务明确显示“当前目录未收录”，不输出硬度预测。
- 输出用于收敛验证优先级；工程放行前仍需完成相稳定性、环境氧化和目标工况力学验证。
