# 1115 晶体发现报告的用户展示规范

本规范用于 OMatG 影子版本的客户报告。参照用户提供的新版 1111 截图，采用完整、严肃的标题和自然语言解释；不将配比优化报告的措辞机械套用到晶体发现。

## 报告顺序

1. 材料设计需求与探索目标：先承接实际用户场景，再说明如何对应到本次组成与结构任务；区分关注性能、参考目标和已确认的必须满足条件。
2. 材料组成范围与计算条件：说明允许、必含及禁止元素，固定化学式、晶胞原子数和候选数量，解释稳定性上限与停止条件。默认参数在值后标明，审计来源保留在计算记录中。
3. 晶体生成、结构优化与性能评价方法：列出有实际计算记录的模型；解释预训练推理、结构优化和生成后筛选。公式与符号完整对应，数学块独占行。
4. 晶体生成结果与候选结构比较：按真实记录显示逐阶段数量，保留全部候选，包括未完成评价的原始生成候选；图表使用同一套任务内唯一的 JC 编号，正文沿用“优选结构（编号）”或“待复核结构（编号）”。
5. 优选晶体的组成、结构、预测性能与验证建议：在同一节汇总优选结构的完整组成、晶格、对称性和所有实际预测性能。零达标时改为“候选晶体的复核与后续验证建议”，不得将未通过方案变成优选。

## 术语与解释

- 方案名称不是材料牌号，中文元素组合名称不是合成已知物相或新颖性的认证；保留原始化学式，原始候选编号仍用于记录和文件关联。
- CSP 固定化学式中的全部元素与计数；DNG 的允许元素不等于必含元素，未要求的元素可以不出现。
- 晶胞是输出结构的周期重复单元，不保证是最小原胞或标准常规晶胞；原子百分比不等同于投料质量比例。
- 稳定性差值即相对同组成竞争相组合的凸包能估算，注明混合参考能量方法。零值、缺失值、未收敛、超限和其他条件未满足必须分开。
- 结构优化只表示局部降低结构能量，不表示已按带隙、模量或强度进行强化学习、多目标优化或模型重新训练。
- 每项性质说明物理含义和单位。原始负带隙及有效质量不得截断或改为正值；近零带隙明确说明需要电子结构复核。
- 不用“卡”“标识”等工程名词命名用户栏目；不在客户表格重复来源列或权重哈希，计算模型和科学口径仍在方法正文中说明。
- 图像与三维模型继续通过既有资产生成、上传和事件路径，维持事件类型及固定 stepID。比较图嵌入4.3，旋转图嵌入5.1，三维事件在报告之后发送；报告和资产发送完成后再发送100%完成事件。保持既有接口和路由。

## 2026-10-01 影子版整体流程调整

- 弹窗展示已了解的应用场景，提供化学式、元素范围和明确开放探索三种起点，保持 v1 `element_system` 单问题结构。
- 当前请求中明确的数值上下限及必含/排除元素进入执行条件；定性描述保留为比较方向。弹窗只补充化学式时仍保留原来的性能要求，上文用于解释场景。
- 计算前给出简短计算方案与实际采用的条件；最终报告先给结论摘要，再解释依据、方法、结果和后续验证。
- 参数表隐藏随机种子、积分网格、模型哈希等审计细节；完整参数保留在原始记录。性能表优先展示本次关注的性质，空缺结果逐项注明原因。
- 0.05 eV/atom 默认用于安排稳定性复核，超参考线仍完成性质评价。接近参考线的数值保留足够精度，使显示值和判定一致。相似结构通过代表结构参与比较。
- 验证与性质评价虽共用既有第三阶段编号，也分别发送实际执行说明。未收敛案例列出完成数量和待补算项，报告、图像与三维模型保持同一结构选择和编号。
- 本次仅在独立影子目录实现并生成预览，线上1115保持原版本。预览使用已保存实算结果，核验原始文件及科学数值未改变，不上传展示资产。

## 交付验证

使用已经保存的真实 CSP、指定元素 DNG、开放空间 DNG 和零达标案例重新生成独立预览，不重新生成晶体或修改输入。`verify_omatg_readable_report.py` 检查科学记录不变、逐项数值保留、方案名称与图一致、表格列数及章节编号一致。服务、图表和计算约束回归分别使用已有依赖环境运行。

这份显示改动是在上一版候选比较图影子版本上的增量，不是可直接覆盖旧 MatterGen 生产服务的完整替换包。线上部署需要另行确认目标和审批。

## 异常与结果空缺的展示

每项缺失说明对应阶段、真实原因、影响和下一步。报告、比较图及 HTTP 结论采用同一份原因解释；保留实际完成的其他计算值。

- 优化未收敛：说明本轮优化已经结束，展示记录的最终力指标、收敛阈值及优化步数。仅有未收敛结论时保留该结论，不推断“已用满迭代上限”。明确继续优化收敛结构后再评价。
- 原子排布未通过：区分初始结构检查与优化后结构检查，列出周期近邻等真实检查原因，建议修正或重新生成。
- 参考相计算失败：区分已有收敛结构与失败的凸包分解、参考能量步骤，保留独立完成的 ALIGNN 性能值。
- 性质预测缺失：分别记录超时、环境无法启动、权重缺失、加载失败、构图失败、非有限预测、结果文件缺失等原因。未要求预测、关闭预测和合并结构的处理方式各不相同。
- 旧结果没有异常记录：明示“结果或停止原因未记录，需要核对任务日志”，不据空值猜测是否执行或为何停止。
- 排队超时、采样超时和零候选：区分停止阶段以及后续没有输入，具体说明恢复资源、重试生成或修复结果读取。
- 可视化失败：区分渲染超时、环境/结果文件异常、源资产缺失、上传失败、对象核验失败与交付异常；说明已完成数值保留及重新生成/发送的方法。
- 追加 CSP：仅在用户请求追加但缺少合规且已完成稳定性评价的起点时说明未执行原因。默认直接 DNG 不额外展示未安排的 CSP。
- 保存记录曾采用硬性稳定性上限时，预览保留历史判定并说明与当前参考线默认行为的区别，避免重新解释历史记录时偷偷改动科学结论。

本次预览沿用原始实算记录，渲染过程不修改收敛阈值、稳定性值、科学文件或推荐条件。新增状态记录只在影子代码中测试，待确认后另行部署。
