# 氧化物玻璃物理约束训练方案（离线）

日期：2026-09-24

## 1. 结论

玻璃不能照搬合金强度随温度变化的残差。现有 SciGlass 严格数据更适合加入三类约束：

1. **输出可行域约束**：密度、弹性模量、热导率和玻璃转变温度为正；泊松比满足弹性稳定性范围。
2. **同成分温度响应一致性**：对 `CTE_FIXED_T` 的同来源、同成分、多温度观测，约束模型复现实测的温度响应斜率，而不是强行规定 CTE 必须单调增加。
3. **弹性关系一致性**：由预测的杨氏模量 `E` 和泊松比 `ν` 派生剪切模量与体积模量，避免多个弹性性质彼此矛盾。

这些属于物理可行域、响应一致性和本构关系约束；在没有控制方程及边界/初始条件时，不应称为严格 PINN。

## 2. 数据审计结果

数据文件：`sciglass_v2_strict_database_observations.csv.gz`

- 总记录：159,461
- 独立成分：67,679
- 来源组：8,088
- `CTE_FIXED_T`：29,032 条，全部具有测试温度
- 同来源、同成分且至少两个温度点的 CTE 组：1,254
- 至少三个温度点的 CTE 组：717
- 温差不少于 10 °C 的相邻 CTE 对：2,575
- 相邻 CTE 响应中约 80.85% 上升、18.33% 下降，因此不适合加入全局正斜率硬约束
- 同来源共同具有 `E、ν、ρ` 的组：3,086，可用于弹性一致性审计
- 热导率仅 647 条，且 647 条全部缺少测试温度；当前不能训练可信的热导率温度残差
- 同来源共同具有热导率、密度、杨氏模量和泊松比的组仅 96 个，只适合探索性机理基线，不足以承担正式约束训练

## 3. 已有约束与建议修正

现有模型已经通过输出变换保证 `Tg、ρ、E、k > 0`。泊松比当前映射到 `[-0.2, 0.6]`，建议改为：

- 一般各向同性弹性稳定范围：`-1 < ν < 0.5`；
- 对当前常规氧化物玻璃数据，可在明确限定适用域后使用 `0 < ν < 0.5`。

建议仅预测 `E` 与 `ν`，并按下式派生其他各向同性弹性模量：

```text
G = E / [2(1 + ν)]
K = E / [3(1 - 2ν)]
```

这样可结构性保证 `G > 0、K > 0`，并避免独立回归头产生互相矛盾的结果。

## 4. P0：CTE 温度响应适配器

不要让温度残差直接更新整个共享 Transformer。推荐结构：

```text
h_comp = GlassTransformer(composition)
y_base = property_head(h_comp, task, temperature)
delta_CTE = response_adapter(stop_gradient(h_comp), temperature)
y_hat = y_base + I(task = CTE_FIXED_T) * delta_CTE
```

适配器零初始化，第一阶段冻结主干；只有验证确认点预测没有明显退化后，才允许极小学习率联合微调。

损失函数：

```text
L = L_point
  + λ_pair * L_pairwise_response
  + λ_bound * L_physical_bounds
```

其中 `L_pairwise_response` 比较同来源、同成分两个温度点的实测与预测差分：

```text
[(ŷ(T2)-ŷ(T1))/(T2-T1) - (y(T2)-y(T1))/(T2-T1)]²
```

它约束的是“同一玻璃成分的实测温度响应”，不预设所有玻璃都具有同一斜率或同一符号。

## 5. 严格验证协议

1. 保持现有成分留出和来源隔离评估。
2. 新增端点回放：对至少三个温度点的同来源—同成分组，隐藏最高温点，只用较低温度点训练。
3. 仅用验证集选择 `λ_pair`，测试集冻结一次评估。
4. 至少运行三个随机种子，并报告均值、标准差和按组 bootstrap 区间。
5. 同时报告：常规点预测 MAE/R²、最高温端点 MAE、温度斜率 MAE、方向一致率和适用域覆盖率。
6. 只有在点预测不显著退化且端点/斜率指标稳定改善时，才保留该约束。

## 6. 后续约束优先级

### P1：弹性稳定性

- 修正泊松比输出范围；
- 由 `E、ν` 派生 `G、K`；
- 对同时具有多项弹性观测的数据检查本构闭合误差。

### P2：机理基线加学习残差

在确认组成单位和氧化物常数后，为密度、弹性模量建立混合定则或体积/键能类基线：

```text
property = mechanistic_baseline(composition) + learned_residual
```

这一方案比把机理描述符简单拼接到网络输入更能体现“模型只学习机理基线未解释部分”。

### 暂缓：热导率温度约束

当前热导率数据没有测试温度，不能识别温度响应。应先补充同成分、多温度热导率数据及测量方法、孔隙率/热历史，再考虑 Debye、弹性波速或最低热导率基线及温度残差。

## 7. 服务与专利边界

- 本方案首先作为离线实验，不修改现有服务和模型权重。
- 专利中可将其表述为“按材料类别和性质选择的物理一致性约束模块”，而不是声称一个统一方程覆盖合金和玻璃。
- 合金采用强度有序约束和条件化温度响应；玻璃采用正值/稳定性约束、CTE 实测响应约束以及弹性本构闭合。二者共享统一训练框架，但使用不同的物理约束算子。
